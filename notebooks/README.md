# Research notebooks

Use notebooks for exploratory work, then promote stable logic into `src/`.

Recommended sequence:
1. Data extraction and profiling
2. Data cleaning and PADD validation
3. Capacity distributions
4. Complexity analysis
5. Statistical hypothesis tests
6. ML clustering and anomaly detection
7. Time-series forecasting
8. Deep-learning experiments
9. Dashboard dataset generation

All experiments should record dataset version, feature definitions, train/test strategy, metrics, and random seed.
